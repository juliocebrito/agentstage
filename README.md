# AgentStage 🎭

Dynamically install and switch multi-agent environments, roles, tones, and custom personas in your AI coding assistants with a single command. Switch instantly between strict technical workflows or fun pop-culture configurations (like *Automan*, *Mr. Robot*, or *Pulp Fiction*).

## 🚀 Installation

Install this skill directly into your compatible development agent (Claude Code, Cursor, etc.) by running:

```bash
npx skills add your-github-username/agentstage
```

## 🛠️ Usage

- Type `/stage` in the agent chat to trigger the interactive menu.
- Choose a preconfigured environment or select option **5** to have the AI guide you through creating a fully custom role.
- Your custom setups are automatically saved locally in an `agentstage.json` file at your project's root.
